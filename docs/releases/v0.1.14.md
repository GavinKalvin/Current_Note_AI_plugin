# Current Note AI v0.1.14

本次公开发布包含自 v0.1.7 后的累计更新，并在发布前升级 Markdown 安全依赖。MIT 开源；最低 Obsidian 1.13.0，仅支持桌面端。

## 更新内容

- 新增 **Kimi Code · Local quota** 与 **ChatGPT · Plan quota**，保留 DeepSeek / Kimi API；模型选择在侧栏顶部。Kimi Code 固定使用 `kimi-code/k3-256k`。
- ChatGPT 可手动选择模型、Reasoning 和 Standard / Fast；补充 `gpt-6.1-sol` 手动选项，并明确标注未验证账户权限。选项存在不代表账户可用，不支持时不静默降级。
- 修复 ChatGPT 在返回有效 SSE 但缺少 Content-Type 时被误判为 “did not return the required event stream”。仍要求完整终止事件，拒绝把 JSON、HTML 或中断响应视为成功编辑。
- Prompt 与回答支持原生文字选择；每条消息的 **Copy** 复制原始 Markdown / LaTeX。用户消息和 AI 回答支持加粗、代码、表格等 Markdown，以及离线 KaTeX 公式渲染。
- 每条 AI 回答气泡外顶部显示生成时的 **Model / Reasoning**，底部显示 **Date & Time**。元数据随历史保存，切换模型不改写旧回答；旧记录缺失项显示 Not recorded，本地应用/撤销标记为 Local action。
- 保留 History、自动命名历史对话、独立 provider 设置、安全编辑预览与撤销。UI 优化参考 Kimi Code **K3-256k** 的限定范围审查。
- 升级 `markdown-it` 至 **15.0.2**，包含 [GHSA-253c-mchw-3w2r](https://github.com/markdown-it/markdown-it/security/advisories/GHSA-253c-mchw-3w2r) 的链接识别拒绝服务修复，并增加重复输入回归测试。

## 安装与更新

1. 下载 `current-note-ai-0.1.14.zip`，解压取得 `main.js`、`manifest.json`、`styles.css`。
2. 将这三个文件放入你的 vault 的 `.obsidian/plugins/current-note-ai/`。更新时仅替换这三个文件，保留 `data.json`；建议先备份原插件目录。
3. 在 Obsidian 中重新加载插件。首次安装请在社区插件设置中启用 Current Note AI。

公式字体和样式打包于 `main.js`，不需要额外资源文件或访问 CDN。完整设置及操作见 [README](https://github.com/GavinKalvin/Current_Note_AI_plugin/blob/main/README.md)，逐版本记录见 [CHANGELOG](https://github.com/GavinKalvin/Current_Note_AI_plugin/blob/main/CHANGELOG.md)。

## 来源配置与边界

- **DeepSeek / Kimi API**：自行配置相应 API 密钥；按服务商 API 计费。
- **Kimi Code**：需已安装并登录 Kimi CLI（0.36.1+），使用会员云端额度，不是离线模型。无需保持 Kimi 图形软件打开；CLI 登录、网络与账户额度仍必须有效。本插件禁用工具、hooks、插件与 MCP，不授权任意本机操作。
- **ChatGPT**：在插件设置中通过 Sign in with ChatGPT 登录；无需 API key，也不读取或复用 Codex 登录凭据。模型、推理与速度受账户权限和服务端支持限制，会员额度共享，并非独立无限额度；若账户启用额外 credits，也可能消耗 credits。
- ChatGPT 当前来源的输出长度为系统提示中的软目标，不宣称已设置服务端硬上限；输入有保守的 32k 编码预算。其他来源的长度控制与自动续写见 README。

## 隐私与安全

本次发布不包含个人笔记、对话数据、API key 或 OAuth 凭据。AI 请求仍会将当前笔记和相关对话发送至所选服务商，请先确认内容适合发送。ChatGPT 登录凭据保存在 vault 外的本机私有文件中；本地历史含笔记上下文，不应公开上传 `data.json`。

模型输出按不可信内容处理：禁用原始 HTML、远程图片、可执行链接及可信 TeX 扩展；数学渲染有大小与展开限制。修改笔记仍须预览和确认；不完整回复不能直接作为成功编辑。发布源码与自动化测试不代表所有账户都获得模型访问权限。
